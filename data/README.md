# Dataset Information

The project uses an immunovirus dataset provided as part of the MA52098 Applied Data Science coursework at the University of Bath.

The dataset contains longitudinal patient information used to explore infection status, treatment, patient characteristics, biomarker measurements and time to liver disease.

The original dataset (`immunovirus.csv`) is not included in this repository because it is not publicly available and is subject to access restrictions.

The R script expects the dataset to be named `immunovirus.csv`. To run the analysis, an authorised copy of the dataset must be placed in the appropriate working directory.
