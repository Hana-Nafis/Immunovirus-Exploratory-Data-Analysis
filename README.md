# Applied Data Science – Immunovirus Dataset

## Project Overview

This project was completed as part of the MA52098 Applied Data Science module for the MSc Statistics and Data Science programme at the University of Bath.

The project involves exploratory data analysis (EDA) of a longitudinal immunovirus dataset using R. It explores infection status, treatment groups, patient characteristics, biomarker measurements and time to liver disease.

## Analysis

The analysis includes:

- Data loading, inspection and preparation
- Conversion of categorical variables into labelled factors
- Missing value assessment
- Descriptive statistics and dataset composition
- Distributions of categorical and numerical variables
- Infection rates across categorical groups
- Comparisons of continuous variables by infection status
- Time to liver disease analysis
- Relationships between baseline and six-month biomarker measurements
- Correlation analysis and heatmap visualisation
