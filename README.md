# Applied Data Science – Immunovirus Dataset

This repository contains my coursework for MA52098 Applied Data Science, completed as part of the MSc Statistics and Data Science programme at the University of Bath.

## Project Overview

The project uses R to conduct exploratory data analysis (EDA) on a longitudinal immunovirus dataset.

The analysis explores:
- Dataset structure and variable characteristics
- Missing values and data preparation
- Categorical and numerical variable distributions
- Infection status across different patient groups
- Relationships between biomarkers and infection status
- Time to liver disease
- Correlations between numerical variables
